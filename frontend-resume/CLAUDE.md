## Project Overview

This is a personal website built with SvelteKit 2, TypeScript, and Tailwind CSS 4. The site includes a blog system powered by mdsvex (Markdown for Svelte) and supports dark/light theming.

## Architecture

### Blog System

The blog is powered by **mdsvex**, which allows writing blog posts as `.svx` files (Svelte + Markdown). Blog posts live in `src/content/blog/`.

**Key files:**
- `src/lib/server/blog.ts` - Server-side blog utilities using Vite's `import.meta.glob` to load posts
- `src/lib/types/blog.ts` - TypeScript interfaces for blog data structures
- `src/content/blog/*.svx` - Blog post files with YAML frontmatter

**Blog post frontmatter structure:**
```yaml
---
title: string
date: string (YYYY-MM-DD)
description: string
tags: string[]
categories: string[]
author: string
published: boolean
coverImage: string (optional, path from /static/)
thumbnail: string (optional, path from /static/)
---
```

**Blog data flow:**
1. Posts are written as `.svx` files in `src/content/blog/`
2. `getAllPosts()` and `getPublishedPosts()` use `import.meta.glob` to dynamically load posts
3. Individual posts are loaded via `getPostBySlug()` which returns both metadata and the Svelte component
4. Related posts are calculated by matching tags (2 points) and categories (3 points)

### Theming System

The site uses a custom theme store (`src/lib/stores/theme.ts`) with light/dark mode:
- Theme preference stored in localStorage
- Theme applied via `.dark` class on `document.documentElement`
- Initialized in `+layout.svelte` on mount to sync with localStorage
- Theme toggle buttons in navbar use Tailwind's `dark:` variants

### Routing Structure

- `/` - Home page
- `/blog` - Blog listing (server-loaded via `+page.server.ts`)
- `/blog/[slug]` - Individual blog posts (client-loaded via `+page.ts` for dynamic imports)
- `/resume` - Resume page (loads from `src/content/resume.svx`)

**Important routing pattern:**
- Blog listing uses `+page.server.ts` for SSR with `getPublishedPosts()`
- Individual blog posts use `+page.ts` (client-side) to dynamically import the post component and calculate related posts

### Configuration

- **svelte.config.js**: Configures mdsvex preprocessor and adds `.svx` extension support
- **vite.config.ts**: Adds Tailwind CSS 4 (via `@tailwindcss/vite`) and devtools-json plugin
- Tailwind configured via `@tailwindcss/vite` plugin (no separate config file needed for v4)

## Key Patterns

### Blog Post Loading

Posts are loaded using Vite's `import.meta.glob`:
```typescript
// Eager loading (for listings)
const modules = import.meta.glob('/src/content/blog/*.svx', { eager: true });

// Lazy loading (for individual posts)
const modules = import.meta.glob('/src/content/blog/*.svx');
const module = await modules[path]();
```

### Type Safety

TypeScript types are auto-generated by SvelteKit in `./$types` imports:
```typescript
import type { PageServerLoad } from './$types';
import type { PageLoad } from './$types';
```

### Svelte 5 Runes

This project uses Svelte 5 with runes syntax:
- `$props()` for component props
- `$theme` for store subscriptions (auto-subscribed in components)
- `{@render children()}` for slot content
